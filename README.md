# بيت النوى

نظام متكامل لمؤسسة بيع المكسرات والحلويات والبهارات والأعشاب والقهوة والتمور والسمن والعسل.

## المميزات
- **لوحة التحكم** (`/`): المنتجات والعروض والمخزون، العملاء، الموظفون، الموردون، البيع، الطلبات، أوامر الشراء، تقارير مالية (إيرادات، ضريبة 15%، ربح إجمالي، قيمة المخزون).
- **صلاحيات**: مدير النظام / مدير / مبيعات / محاسب.
- **المحلل**: يقترح أوامر الشراء والكميات من مبيعات آخر 30 و90 يوماً، ومدة التوريد، ومخزون الأمان، وموسمية السوق السعودي (رمضان، العيد، الحج، اليوم الوطني، الشتاء/الصيف). ينشئ أوامر شراء مجمّعة حسب المورد.
- **السوق والأخبار الرسمية**: الأخبار لا تُعرض إلا إذا كان مصدرها نطاقاً رسمياً من قائمة محددة في `lib/market.js` (واس، تداول، ساما، الهيئة العامة للإحصاء، وزارة المالية، وزارة التجارة، هيئة الزكاة والضريبة والجمارك، هيئة الغذاء والدواء، وزارة البيئة والمياه والزراعة، المركز الوطني للنخيل والتمور، ومصادر خليجية ودولية رسمية مثل صندوق النقد والبنك الدولي والفاو). على كل خبر شارة المصدر، ويُرفض أي نطاق مشابه أو مزيف. المؤشرات المالية (تاسي، برنت، القهوة...) من Yahoo Finance وهي مصدر تجاري غير رسمي، وتُعرض مع روابط المصادر الرسمية للتحقق. تحتاج اتصالاً بالإنترنت.
  - لإضافة جهة رسمية أخرى أضفها إلى `OFFICIAL` في `lib/market.js`.

## التشغيل
يتطلب Node.js 22.13 أو أحدث. لا توجد حزم للتثبيت.

```bash
node seed.js      # اختياري: بيانات تجريبية (تطبع كلمة مرور المدير)
node server.js    # http://localhost:3000
```

عند أول تشغيل يُنشأ المستخدم `admin` بكلمة مرور عشوائية تُطبع في الطرفية (أو حددها بالمتغير `ADMIN_PASSWORD`). غيّرها من الإعدادات.

متغيرات البيئة: `PORT`, `DATA_DIR` (مكان قاعدة البيانات)، `APP_SECRET`, `ADMIN_PASSWORD`.

## ملاحظات
- أسعار البيع شاملة الضريبة (نسبة الضريبة من الإعدادات).
- التكلفة تُحدّث بمتوسط مرجح عند استلام أمر الشراء.
- اقتراحات المحلل إرشادية؛ راجعها قبل الاعتماد. جودتها تزداد بتراكم بيانات المبيعات.
- استخدم HTTPS (خلف nginx أو منصة استضافة) عند النشر.
