# بيت النوى

نظام متكامل لمؤسسة بيع المكسرات والحلويات والبهارات والأعشاب والقهوة والتمور والسمن والعسل.

## المميزات
نظام **مركز متابعة** بلا إصدار فواتير.
- **صفحة هبوط** (`/`) وصفحة **العروض العامة** (`/offers`): تعرض العروض السارية فقط (السعر قبل وبعد وتاريخ الانتهاء) دون سلة أو طلب. المنتج الذي نفد مخزونه لا يظهر فيها.
- **مركز المتابعة** (`/admin`): مؤشرات تفاعلية (إيراد، ربح، هامش، مقارنة بالفترة السابقة، فئات، أفضل المنتجات والعملاء)، المخزون، العروض، العملاء، الموظفون، الموردون، أوامر الشراء.
- **ثلاث طرق لإدخال المبيعات** (متابعة فقط، بلا فواتير):
  1. **تسجيل يدوي** سريع (التاريخ، المنتج، الكمية، السعر).
  2. **استيراد Excel/CSV**: احفظ الملف CSV UTF-8 أو الصق الخلايا. الأعمدة: التاريخ، المنتج (اسم أو SKU)، الكمية، [السعر]، [رقم العملية]، [العميل]. يوجد فحص مسبق وتقرير أخطاء، وإعادة رفع الملف لا تكرر المبيعات.
  3. **ربط برنامج المبيعات (API)** بمفتاح من الإعدادات:
     - `POST /api/integration/sales` بالترويسة `X-API-Key` وجسم `{ "sales": [{ "ref": "1001", "date": "2026-11-01", "items": [{ "sku": "DATE-01", "qty": 2, "price": 45 }] }] }`
     - `POST /api/integration/stock` بجسم `{ "items": [{ "sku": "DATE-01", "stock": 120 }] }` لمزامنة المخزون.
     - تكرار `ref` يُتجاهل. الخصم من المخزون في المبيعات معطّل افتراضياً (`"update_stock": true` لتفعيله).
- **صلاحيات**: مدير النظام / مدير / مبيعات / محاسب.
- **المحلل**: يقترح أوامر الشراء والكميات من المبيعات المسجلة، ومدة التوريد، ومخزون الأمان، وموسمية السوق السعودي (رمضان، العيد، الحج، اليوم الوطني، الشتاء/الصيف).
- **السوق والأخبار الرسمية**: الأخبار لا تُعرض إلا إذا كان مصدرها نطاقاً رسمياً من قائمة محددة في `lib/market.js` (واس، تداول، ساما، الهيئة العامة للإحصاء، وزارة المالية، وزارة التجارة، هيئة الزكاة والضريبة والجمارك، هيئة الغذاء والدواء، وزارة البيئة والمياه والزراعة، المركز الوطني للنخيل والتمور، ومصادر خليجية ودولية رسمية). على كل خبر شارة المصدر. المؤشرات المالية من Yahoo Finance (مصدر تجاري غير رسمي) وتُعرض مع روابط المصادر الرسمية. لإضافة جهة أضفها إلى `OFFICIAL`.

## التشغيل
يتطلب Node.js 22.13 أو أحدث. لا توجد حزم للتثبيت.

```bash
node seed.js      # اختياري: بيانات تجريبية (تطبع كلمة مرور المدير)
node server.js    # http://localhost:3000  (لوحة التحكم: /admin)
```

عند أول تشغيل يُنشأ المستخدم `admin` بكلمة مرور عشوائية تُطبع في الطرفية (أو حددها بالمتغير `ADMIN_PASSWORD`). غيّرها من الإعدادات.

متغيرات البيئة: `PORT`, `DATA_DIR` (مكان قاعدة البيانات)، `APP_SECRET`, `ADMIN_PASSWORD`.

## ملاحظات
- أسعار البيع شاملة الضريبة (نسبة الضريبة من الإعدادات).
- التكلفة تُحدّث بمتوسط مرجح عند استلام أمر الشراء.
- اقتراحات المحلل إرشادية؛ راجعها قبل الاعتماد. جودتها تزداد بتراكم بيانات المبيعات.
- استخدم HTTPS (خلف nginx أو منصة استضافة) عند النشر.
